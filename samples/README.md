# 모델 설치 없이 실제 실행 살펴보기

이 폴더의 gzip JSON은 실제 로컬 모델과 하네스를 실행해 저장한 기록입니다. 애니메이션을 위해 만든 가상 이벤트가 아닙니다. `Start-AgentLens.ps1 -SamplesOnly`로 열 수 있습니다.

| 기록 | 실행기 | 살펴볼 것 |
| --- | --- | --- |
| feedback | llama.cpp / Qwen3-4B | 빠진 검사를 지적 → 다음 모델 입력에 보완 → 실제 check_file. 과거 버전은 JSON 값까지 검증하지 않아 요청한 값을 놓쳤다는 한계도 포함 |
| verified-write | llama.cpp / Qwen3-4B | read/write/check와 실제 JSON 값 비교, 244개 이벤트, 마지막 브라우저 본문 반영 |
| tensors | Python / Qwen3-0.6B | 실제 모델·계산 도구 왕복, 토큰·임베딩·Q/K/V·attention·KV 수치 표본 |
| team | llama.cpp / Qwen3-4B | 실제 주 에이전트와 두 하위 대화, 파일 읽기, 계산 대기, 결과 합류, 전체 모델 6회 |
| deep | llama.cpp / Qwen3-4B | 같은 대화의 답변 후보에 점검 지시를 추가하고 실제 세 번째 모델 호출 |
| compaction | llama.cpp / Qwen3-4B | 이전 원문 2,488자 → 실제 모델 요약 73자 → 파일 저장 → 다음 입력. 원문 저장소 스냅샷 포함 |
| summary-reuse | llama.cpp / Qwen3-4B | 요약을 다시 생성하지 않고 저장된 요약과 최근 원문을 읽어 응답. 원문 저장소 스냅샷 포함 |
| repeat-before | llama.cpp / Qwen3-4B | 필수 도구를 호출하지 않고 보완 지시 후에도 같은 답변을 반복, 8회 호출 한도로 실패 |
| repeat-guard | llama.cpp / Qwen3-4B | 첫 모델 입력이 같은 재실행에서 동일한 미검증 응답을 3회 감지해 실패로 중단 |

`index.json`의 id는 원본 실행 ID입니다. API와 화면은 `sample-슬러그`로 구별하며 원본 ID를 별도 보존합니다. 사용자 홈·프로젝트 경로는 `<USER_HOME>`·`<PROJECT>`로 익명화했습니다. 프롬프트·응답·수치·당시 소스는 보존했습니다. 현재 소스가 이후에 바뀌었을 수 있으므로 기록 속 스냅샷을 기준으로 읽으세요.

재생은 새 모델 계산이나 도구 실행을 일으키지 않습니다. 기록에 browser.render가 있다면 당시 브라우저가 보고한 사실이며, 지금 재생 화면의 새 실행 증거가 아닙니다. 토큰·KV 표본은 관측값이지만 모델의 숨겨진 사고를 해독한 값은 아닙니다.

파일의 바이트 수와 해시는 익명화 전 실제 읽기에서 측정한 값입니다. 표시 문자열의 경로를 익명화한 뒤 다시 계산한 값은 아닙니다. 대화 저장소 스냅샷은 해당 예제 실행을 마친 시점의 디스크 상태입니다.

자체 코드와 이 예제 기록은 저장소의 MIT 라이선스로 제공합니다. 모델·엔진의 가중치나 실행 파일은 포함하지 않습니다.
