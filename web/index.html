시간이 지나면 왜 반복할까?

이 하네스는 최근 두 대화 묶음을 다시 넣습니다. 지적이 오래된 대화와 함께 빠질 수 있습니다. 저장된 지적과 실제 messages의 일치를 위에서 확인하세요. ‘동일 요청 지적 재포함’을 켜면 같은 요청의 저장된 지적을 다시 전달합니다. 포함 여부와 실제 행동은 별도로 확인해야 합니다.

이 실행 경로에는 모델을 재학습하는 단계가 없습니다. 지적이 입력에 있어도 지시 충돌·모델 능력·출력 설정 등에 따라 실수할 수 있으며, 한 번 성공했다고 지속적인 학습이 일어났다고 판단하지 않습니다.

실습 문제

AGENTS.md를 실제로 여는 주체는 누구일까?

규칙 로더를 작성한 하네스입니다. file.open → file.read → rules.wrap → context.assemble의 코드와 messages를 확인하세요.

모델이 “도구를 썼다”고 답하면 실제로 실행한 것일까?

tool.dispatch는 요청이고 tool.result가 실제 함수 결과입니다. 답변 문장·계획 체크·검증 게이트를 각각 대조하세요.

지적을 저장했다면 다음에도 항상 알고 있을까?

저장 파일과 현재 모델 입력은 별개입니다. 오류·지적·기억 화면의 입력 포함 여부와 실제 후속 행동을 따로 확인하세요.

구문 검사가 통과하면 정의되지 않은 이름도 없을까?

lsp_demo.py로 직접 비교하세요. compile은 통과하지만 언어 서버의 pyflakes 진단은 missing_amount를 찾습니다.

두 번의 실제 실행

사용 안내

이 앱은 프롬프트가 실제 행동으로 이어지는 과정을 기록합니다. 모델의 숨겨진 생각을 읽는 기능은 아닙니다.

웹 데모는 저장된 기록을 재생합니다. 실행·저장·비교는 Windows PC에 설치한 앱에서만 됩니다.

  1. 배우기 — 실제 기록을 단계별로 따라가는 강의입니다. 모델을 설치하지 않아도 볼 수 있습니다.
  2. 기록 보기 — 왼쪽 위 메뉴의 예제 기록을 직접 재생할 수도 있습니다. 저장 기록과 지금 실행하는 계산을 구분해 표시합니다.
  3. 실행 — 오른쪽 아래 입력란에 요청을 쓰거나 예제를 고른 뒤 실행하세요. 하네스가 실제 파일을 읽고 로컬 모델을 호출합니다.
  4. 따라가기 — 오른쪽의 장면을 고르거나 재생하세요. 세부는 장면을 펼치거나 전체 기록에서 봅니다.
  5. 멈추기 — 실행 전에 단계 정지를 켜세요. 교육용은 실제 forward 내부 관찰 지점에서도 멈춥니다. 빠른 실행기는 하네스 쪽에서 멈춥니다.
  6. 바꾸기 — 메뉴의 파일을 열어 수정·검사·저장하세요. 다음 실행에서 변경을 확인할 수 있습니다.
  7. 비교 — 구성 · 비교의 비교 실험에서 실제 호출 수·입력 토큰·계산 시간을 확인하세요.
  8. 모드 — 작업 방식을 바꿔 지침·권한·예산·대화 분리의 차이를 확인하세요. 구조도 위 에이전트 선택은 해당 대화의 마지막 기록으로 이동합니다.
