# 테스트와 측정

검토일: 2026-11-08. Windows x64, Intel Core Ultra 7 258V / 32 GB / Intel Arc 140V에서 확인했습니다. 아래 결과는 해당 환경의 관측이며 일반적인 성능 보증이 아닙니다.

## 자동 검증

```powershell
uv run --extra reference --extra integrations --offline python -m unittest discover -s tests -v
node --test tests/architecture.test.cjs
```

79개 Python 테스트를 실행합니다. 모의 모델로 도구 루프·권한·완료 조건·기억·편집·HTTP 경계를 검사합니다. 작은 무작위 Qwen 모델로 실제 KV 사용/전체 재계산의 결과와 접두부 처리를 검사합니다. MCP는 별도 stdio 프로세스를, LSP는 설치된 실제 pylsp의 진단·심볼·정의·문서 변경을 검사합니다. 모드 검증에는 독립 하위 컨텍스트·권한 제한·실제 결과 합류·대기 중 중지 전파·에이전트별 지적 연결을 포함합니다. 이 숫자는 다운로드한 모델이 모든 지시를 잘 따른다는 뜻이 아닙니다.

## 실제 모델과 화면 검증

최종 환경에서 79개 Python 테스트와 구조도 Node 테스트 2개가 통과했습니다. 공개할 파일만 복사한 별도 사본에서도 `python -S -m unittest discover -s tests -q`가 통과했습니다. 이때 추가 패키지가 필요한 신경망 2개·LSP 1개는 건너뛰었고, MCP와 하네스·재생 경로는 표준 라이브러리로 검사했습니다.

- **파일 수정:** 4B가 4번의 모델 호출과 read_file/write_file/check_file을 거쳐 JSON의 practice=true를 실제 결과로 확인했습니다. 244개 이벤트를 JSON으로 내보내고 브라우저 본문 반영까지 확인했습니다. 이 기록은 배포 샘플에 포함했습니다.
- **계산과 텐서:** 0.6B가 add_numbers를 요청하고 385를 받아 답한 463개 이벤트를 확인했습니다. 실제 텐서·KV 표본을 포함하며 배포 샘플에 보존했습니다.
- **MCP 비교:** 같은 요청에서 연결 전에는 내장 계산 도구, 연결 후에는 실제 MCP 계산 도구를 사용했습니다. 공개 도구 수가 6개에서 7개로, MCP 전송·수신이 0개에서 6개로 변했습니다. 양쪽 답은 385였지만 연결 전 모델은 “MCP가 없으면 없다고 답하라”는 지시를 놓쳤습니다.
- **LSP 비교:** 연결 전의 구문 검사는 통과했습니다. 모델이 파일을 읽고 미정의 이름을 추측한 것과 별도로, 연결 후에는 실제 언어 서버의 진단을 받았습니다. 공개 도구 6→9개, LSP 전송·수신 0→6개, 모델 호출 3→2회였습니다. 후속 답변은 정규화한 8행·12열을 사용했습니다.
- **생성 중 KV 비교:** 같은 123개 입력 토큰에서 5개 토큰을 생성했습니다. KV를 끄면 forward 입력 누적 625, 켜면 127이었고 출력은 같았습니다. 요청 간 접두부 재사용은 양쪽 모두 끈 별도 실험입니다.
- **집중 비교:** 같은 요청·모델에서 기본은 모델 2회·입력 2,451토큰·12.59초, 집중은 모델 3회·입력 4,242토큰·25.6초였습니다. 집중의 세 번째 실제 요청에 점검 지시가 들어갔습니다. 답변 품질 향상을 입증한 수치는 아닙니다.
- **하위 위임:** 실제 4B 모델이 Explore·Oracle에 두 작업을 전달했습니다. 각 하위는 모델 2회와 파일 읽기 1회, 주 에이전트는 모델 2회와 위임 1회였습니다. 전체 모델 6회·도구 3회·입력 7,537토큰, 계산 차례 대기 누적 약 9,421ms를 기록했습니다. 하위 보고와 상태가 실제 주 모델의 다음 입력에 포함됐습니다. 704개 이벤트를 익명화 샘플에 보존했습니다.
- **위임 비교:** 같은 일반 요약 요청에서 단일 모드는 모델 2회·입력 2,451토큰·13.53초, 위임 모드는 모델이 하위 한 개를 선택해 전체 모델 4회·입력 5,199토큰·22.92초였습니다. 모드 선택이 하위 두 개나 속도 향상을 강제하지 않는다는 사실도 확인했습니다.
- **실제 요약·재사용:** 공개 실습 대화 2,488자를 실제 4B 모델이 73자로 요약했습니다. 원문은 보존하고 요약·최근 원문으로 답변했습니다. 이 실행의 요약+답변은 입력 2,226토큰·출력 81토큰이었고 다음 요청은 추가 요약 없이 입력 441토큰·출력 13토큰으로 응답했습니다. 두 실제 기록과 당시 원문 저장소를 배포 샘플로 보존했습니다.
- **화면:** 실제 단계 정지·다음·계속, 원문/코드 이동, 편집/복원, 저장 기록 재생, 오류 대조, 반응형 화면을 브라우저에서 확인했습니다.

A 다음 B를 한 번 실행한 시간 차이는 순서·캐시·워밍업·관찰 비용의 영향을 받습니다. MCP나 LSP를 붙이면 항상 빨라지거나 정확해진다고 주장하지 않습니다.

## 알려진 제한

- 요약은 완료한 대화를 다음 요청 전에 처리합니다. 현재 도구 루프의 중간 컨텍스트 초과 자동 관리나 모든 사실의 의미 보존 검증은 포함하지 않습니다.
- 실제 수치도 선택한 레이어·head·위치·차원의 표본입니다. 전체 텐서·모든 코드 줄·숨겨진 사고를 기록하는 제품이 아닙니다.
- MCP는 단일 stdio 프로필, 명시적 도구 허용 목록, 단순 스칼라 schema와 complete 결과만 지원합니다. 모든 버전·서버의 적합성 검증이나 HTTP/OAuth는 포함하지 않습니다.
- LSP는 Python의 진단·문서 심볼·정의를 지원합니다. 외부 서버 내부의 모든 연산을 추적하지는 않습니다.
- 지적 재포함은 완료한 대화의 같은 요청 해시에 대한 명시적 정책입니다. 모델 훈련이 아니며, 포함된 지적을 모델이 항상 따르지는 않습니다.
- 하위 작업은 최대 3개, 기본 작업자는 2개이며 실제 모델 계산은 직렬화합니다. 재귀 위임·모델별 라우팅·Atlas 인계·전체 ultrawork/팀 프로토콜은 포함하지 않습니다.
- 모델·스킬·규칙·계획은 실행 권한을 강제하지 않습니다. Python 정책과 도구 결과 검증이 별도로 필요합니다. 이 앱은 적대적 코드용 OS 샌드박스가 아닙니다.
- Windows 시작 스크립트와 이 PC의 실제 모델 경로를 확인했습니다. Linux/macOS 수동 실행 안내는 해당 OS에서의 설치·화면 검증을 대신하지 않습니다.
- 가중치·개인 대화·실행 기록·가상환경을 제외하고 자체 MIT 코드와 공개 실습용 익명화 샘플을 배포합니다.
